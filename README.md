## tools

Work directly with CLI tools.

API subject to change in very backwards incompatible ways.

You can use this library via maven, just add a new dependency to the pom.xml file of your project.
```
<dependency>
    <groupId>dev.mccue</groupId>
    <artifactId>tools</artifactId>
    <version>2025.01.31</version>
</dependency>
```
